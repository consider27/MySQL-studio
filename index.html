MySQL Studio 使用说明

执行 SQL：把查询粘贴到编辑器，点击执行或按 Ctrl / Cmd + Enter。桌面版会通过安全桥接启动本地 mysql.exe，并把 TSV 输出解析成表格。

连接要求：必须配置可用的 mysql.exe、MySQL 服务、主机、端口和账号密码。连接失败会弹出错误说明，不会使用模拟数据。

支持的常用工作流：数据库对象浏览、查询编辑、多语句结果预览、结果分页、复制/CSV 导出、Explain、查询历史、收藏和深色主题。

建议使用 MySQL 8.0+ 客户端，并确保系统 PATH 中能找到 mysql.exe。

无法使用 MySQL

没有成功连接到 MySQL。

请确认已安装 MySQL Server 并且服务正在运行。mysql.exe 只是客户端，不能单独提供数据库服务。
